# 🎓 Student Result Management System

A web-based **Student Result Management System** built with **Django** that helps educational institutions efficiently manage students, classes, subjects, marks, and results through an intuitive admin dashboard.

---

## 📌 Features

- 🔐 Secure Admin Login
- 👨‍🎓 Student Management
- 🏫 Class Management
- 📚 Subject Management
- 📝 Result Management
- 📊 Student Result Generation
- 📄 Student Result Search
- 📈 Dashboard with Statistics
- ✏️ Edit & Update Records
- 🗑️ Delete Records
- 📱 Responsive User Interface

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Student-Result-Management.git
```

### Move to Project

```bash
cd Student-Result-Management
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Linux / Mac

```bash
source venv/bin/activate
```

### Install Requirements

```bash
pip install -r requirements.txt
```

### Apply Migrations

```bash
python manage.py migrate
```

### Create Superuser

```bash
python manage.py createsuperuser
```

### Run Server

```bash
python manage.py runserver
```

Open

```
http://127.0.0.1:8000/
```
